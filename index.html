tech-shorts

For the YouTube channel @learnbySaurabhSrivastava (Learn & Implement by Saurabh)

tech-shorts is a personal tool that makes short SQL and Python tutorial videos (a small example, the real output of the code, and a voice-over) and uploads them to the owner's own YouTube channel.

It only asks for permission to upload videos to that channel. It does not read or store any other data.
